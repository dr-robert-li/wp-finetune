## Code/doc mismatches and quirks (documented, not fixed)
1. `dimensions.*.low_rate` and the anti-pattern/pattern thresholds (≤ 4, ≥ 8) are hard-coded in aggregate.py. They ignore `WPJUDGE_CAP_THRESHOLD`. If an operator changes the cap threshold, `low_rate` no longer matches the cap.
2. The size-limit middleware runs before auth. An oversized or chunked POST without a key gets 413/411, not 401. Harmless.
3. FastAPI `/docs` and `/openapi.json` are not behind the API key.
4. The webhook URL is checked for its scheme only, not its host (SSRF possible from inside the container network). Documented.
5. All-in-one: `LLAMA_PARALLEL` does not set `WPJUDGE_WORKERS` (compose links them; the all-in-one image does not). Documented.
6. Compose passes only `WPJUDGE_BASE_URL`, `WPJUDGE_MODEL_FILE`, `WPJUDGE_WORKERS` and `WPJUDGE_API_KEY` to the harness. Other knobs (for example `WPJUDGE_TEMPLATES`) need a compose edit. Documented.
7. The CLI detects the archive type by content, so plain `.tar` works. The API accepts only the `.zip`, `.tar.gz` and `.tgz` suffixes (415 otherwise).
8. Bool env parsing: an empty value (`WPJUDGE_TEMPLATES=`) means false.
9. `summary.verdict_counts` can hold extra keys, such as `null`, if a judged unit's JSON has a numeric `overall_score` but no `verdict`. Not documented as a feature. The README says it "always has PASS and FAIL".
10. Retention uses the job directory's mtime, which is the last file create/replace in it. That is about when the job ended, not when it was submitted. The README says "last change".
11. PLAN.md W5 names `docker/entrypoint.sh`. The real files are `docker/llama-entrypoint.sh` and `docker/allinone.sh`. SPEC R3.1 says `hf download`; A2 replaced that with curl, and the docs follow the code.
12. `research/` is excluded by `.dockerignore`, not by `.gitignore`. Whether to commit it is the orchestrator's decision.
