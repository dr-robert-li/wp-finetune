# W1 extract — build report

## SIGNATURES (W3/W4 depend on these)
```python
from wpjudge.extract import load_target, collect_units, Rejected
load_target(path, dest=None, cfg=None) -> (root_dir: Path, target_meta: dict)
collect_units(root_dir, cfg=None)      -> (units: list, skips: list, files_scanned: int)   # 3-tuple
```
- **collect_units returns a 3-tuple** (binding change 7). `files_scanned` = regular (non-symlink) `.php` files walked,
  INCLUDING files then skipped (vendor/test/...). W4 puts it into `target.files_scanned`.
- `target_meta = {"name", "type": "plugin"|"theme", "sha256"}` — no `files_scanned` key (W4 merges it in).
  name: dir name; for an archive, the single top-level dir name, else the archive name minus `.zip/.tar.gz/.tgz/.tar`.
  type: `theme` iff `<root>/style.css` contains `Theme Name:`. sha256: of the archive bytes, `""` for a dir.
- `dest`: archives are extracted into `<dest>/src` (created; must not already exist). `dest` may exist
  (TemporaryDirectory, job dir). If `dest` is None a `tempfile.mkdtemp()` is used and the caller owns cleanup.
  Directory input is never copied. `cfg` defaults to `wpjudge.config.load()`.
- Errors: `Rejected(ValueError)` for missing path, non-archive, unsafe member path (`..`, absolute, `C:`),
  zip symlink, tar symlink/hardlink, `> cfg.max_files` members, `> cfg.max_total_mb` uncompressed,
  ratio `> cfg.max_ratio` (only when uncompressed > 10 MB, per r1), and corrupt archives
  (BadZipFile/TarError/EOFError/OSError are wrapped). All checks run before any byte is extracted; tar also
  uses `extractall(filter="data")`.

## Behaviour (per PLAN contracts + r1)
- Unit/Skip dicts exactly as contracts. Per-file skips `line 0, name ""`; per-unit skips (`tiny`, `parse_error`)
  and template skips (`tiny`, `too_large`, `parse_error`) carry the real line / name (`<template>` at line 1).
- Skip rules: r1 list (path segments vendor, node_modules, test(s)/bin/docs -> test, build/dist -> build;
  `test-*`, `*-test.*`, `*Test.php`/`*Tests.php`, `extends WP_UnitTestCase|TestCase`; `*.asset.php` -> build;
  `.min.php` or avg line length > 200 on > 2000 chars -> minified). The 2 has_test_code false-positive fixes
  applied (no bare `PHPUnit`, no lowercase `test.php` suffix; `abtest.php` is judged, asserted in the test).
- Functions under 3 lines -> tiny. Truncation at `cfg.max_chars` at the last newline + `// ... [truncated by wpjudge]`,
  `truncated: True`; `loc` stays the real line count.
- Templates on by default, `cfg.templates=False` (`WPJUDGE_TEMPLATES=0`) disables. Templates never truncated.
- Walk uses `os.walk` (does not follow symlinked dirs; Path.rglob on 3.12 is murkier) and skips symlinked files.

## Deviations from r1 prototype (small)
- Template candidate only when the file produced no units AND no per-unit skips (prototype: no tiny skips) —
  stops a file whose only function is a parse_error from becoming a template.
- Template with a tree-level parse error -> `parse_error` skip instead of a unit.
- Ratio/size messages split into separate errors.

## Fix round 1 (EVAL_W1.md)
All 7 defects fixed (8 was a no-op note). `pytest tests/test_extract.py -q` -> 10 passed (5 old + 5 regression).
extract.py now 233 lines, test_extract.py 199.

1. **major, `_code` kept attributes/modifiers after a docblock.** Code is now `docblock.text + "\n" +
   src[function keyword .. node end]`, so `#[Attr]` and `final public static` are always dropped.
   Test: `test_docblock_drops_attributes_and_modifiers` (asserts `*/\nfunction s()`, no `public`, no `#[Pure]`).
2. **major, tar guards ran after `getmembers()` buffered the archive.** Now `for m in t:` with a running
   count and size; `_check_totals` runs per member, so it stops at member max_files+1 or the first oversize
   header. `extractall(filter="data")` unchanged. Test: `test_tar_count_guard_streams` (getmembers patched to
   fail; asserts "too many files" after reading ~21 of 50 headers).
3. **minor, `__MACOSX/` blocked unwrap.** It is removed from `<dest>/src` after extraction, before the
   single-top-level-dir check. Test: `test_macosx_zip_unwrapped` (name/type theme, no junk skip, scanned 1).
4. **minor, nested class/interface became a template.** The walk sets `owned` if any OWNERS or anonymous_class
   node appears anywhere; owned files never become templates. Test: braced-namespace interface and
   `if (!class_exists) { class X }` give no unit and no skip.
5. **minor, unrecognised functions dropped silently.** An ERROR/missing node with no function ancestor adds one
   per-file `parse_error` skip (`line 0, name ""`), unless the file already became a template unit/skip.
   Units that parsed in the same file are still emitted. Test: `err.php` case.
6. **minor, `.PHP` not scanned.** Match is `f.lower().endswith(".php")`. Test: `UP.PHP` judged, counted.
7. **minor, mkdtemp leak on reject with dest=None.** On Rejected, rmtree the mkdtemp dir (or `<dest>/src` when the
   caller passed dest; the caller's dest itself is left alone). Test: `test_rejected_without_dest_leaves_no_tempdir`.
